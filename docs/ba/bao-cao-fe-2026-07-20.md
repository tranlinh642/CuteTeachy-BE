Báo Cáo Kiến Trúc Frontend Monorepo - CuteTeachy

Ngày lập: 20/07/2026

1. Tổng quan Cấu trúc Thư mục

Dự án sử dụng mô hình Monorepo (quản lý bởi Turborepo và pnpm) nhằm tách biệt giao diện UI nhưng chia sẻ 100% logic nghiệp vụ.

Nhóm 1: 

apps/

 (View Layers - Tầng Hiển Thị)

Tầng này KHÔNG chứa logic nghiệp vụ cốt lõi, chỉ chứa UI components và routing.

apps/web/

: Ứng dụng Next.js (Web). Phụ trách SEO, Admin Dashboard hoặc Web App cho người dùng. Mọi file cấu hình (

package.json

, 

next.config.js

) đã được thiết lập để liên kết với các package dùng chung.

apps/mobile/

: Ứng dụng React Native sử dụng Expo Router. Là bản App dành riêng cho iOS (hoặc Android nếu cần sau này). Sử dụng bộ UI Native chuyên biệt.

Nhóm 2: 

packages/

 (Core Logic - Tầng Nghiệp Vụ Chia Sẻ)

Đây là trái tim của dự án, mọi đoạn code dùng chung giữa Web và App phải được đặt ở đây:

packages/api/

: Nơi khởi tạo Axios/Fetch clients, chứa các interceptors (đính kèm Token), và các Custom Hooks (React Query/SWR) để Web và App dùng chung khi gọi lên NestJS.

packages/database/

: Chứa toàn bộ cấu hình WatermelonDB (schema, models) và Sync Engine. Đây là bộ não cho tính năng Offline-first, tự động đồng bộ dữ liệu với server.

packages/types/

: "Single Source of Truth" cho toàn bộ Type/Interface TypeScript của dự án. Mọi thay đổi về DTO của NestJS sẽ được cập nhật tại đây.

Nhóm 3: Configurations (Cấu hình)

pnpm-workspace.yaml

: Trái tim của Monorepo, định nghĩa các workspace để pnpm biết cách liên kết chúng lại bằng symlink.

turbo.json

: Cấu hình pipeline của Turborepo, giúp cache các bước build/lint để tăng tốc độ phát triển lên gấp nhiều lần.

2. Các Bước Đầu Tiên Cần Thiết Nhất

Để dự án bắt đầu "chạy" thực tế, Senior FE cần thực hiện các công việc ưu tiên sau:

Thiết lập Types:

 Mở 

packages/types/src/index.ts

 và định nghĩa các interface gốc (ví dụ: 

Task

, 

User

).

Khởi tạo Database Schema:

Vào 

packages/database/

 cài đặt WatermelonDB.

Viết cấu trúc bảng trong 

schema.ts

.

Tạo các Models (

User.ts

, 

Task.ts

) mapping với Schema.

Setup API Client:

Vào 

packages/api/

 setup một Axios Instance chung trỏ về domain của NestJS (ví dụ: 

http://localhost:3000

).

Kết nối vào Apps:

Tại 

apps/web/src/app/layout.tsx

 và 

apps/mobile/src/app/_layout.tsx

, bọc ứng dụng bằng các Provider cần thiết (DatabaseProvider, QueryClientProvider).

3. Hướng dẫn Test cơ bản

Trong Monorepo này, việc test được chia làm 2 giai đoạn:

Test Logic Độc Lập (Unit Test)

Vì logic đã được tách riêng vào 

packages/

, bạn có thể test độc lập mà không cần chạy UI:

Cài đặt 

vitest

 hoặc 

jest

 vào trong thư mục 

packages/api

 hoặc 

packages/database

.

Viết các file 

.test.ts

 để mock API calls và test các hàm tính toán nghiệp vụ.

Test Luồng UI (Integration/E2E Test)

Để chạy Web:

 Đứng ở thư mục gốc 

CuteTeachy-FE

, chạy lệnh 

pnpm --filter web dev

. Mở trình duyệt tại 

http://localhost:3000

.

Để chạy Mobile:

 Chạy lệnh 

pnpm --filter mobile start

. Tải app Expo Go trên iPhone, quét mã QR hiện ra trên màn hình Terminal để test trực tiếp trên điện thoại thật.

Chạy song song (Turborepo):

 Chạy 

pnpm run dev

 ở thư mục gốc, Turborepo sẽ tự động kích hoạt cả server Web lẫn Mobile cùng một lúc.
